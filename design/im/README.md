# Макет главной страницы (4 формата экспорта)

Сюда кладут один и тот же макет страницы в четырёх вариантах экспорта, например:

- `*.png` — растровый экспорт
- `*.svg` — векторный экспорт
- `*.pdf` — PDF
- `*.jpg` или другой формат — по необходимости

По этим файлам сверяют вёрстку в `packages/web`.
